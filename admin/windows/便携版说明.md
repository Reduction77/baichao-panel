# 白潮 Wiki 管理后台 v1.2.0 · Windows 便携版

## 启动

1. 完整解压 ZIP 到固定文件夹，不要直接在压缩包里运行。
2. 双击 BaichaoWikiAdmin.exe，或双击“启动管理后台.bat”。
3. 浏览器会自动打开管理页面，保持启动窗口开启。退出时关闭窗口或按 Ctrl+C。

本版已包含 Python 运行环境，不需要安装 Python、Docker 或 Git。支持 Windows 10/11 的 x64 电脑，无需管理员权限。

如果启动失败，程序会保留提示。也可以运行“启动管理后台.bat”，方便查看退出信息。程序默认只监听 127.0.0.1，不提供公网后台。

## 第一次连接

打开“连接设置”，默认仓库 Reduction77/baichao-wiki、分支 main。

前往 https://github.com/settings/personal-access-tokens 创建 Fine-grained personal access token，仅授权自己的 Wiki 仓库。仓库权限开启 Contents: Read and write；如需在后台查看自动发布状态，再开启 Actions: Read-only。不需要 Workflows 写权限。

在本机页面填入令牌并保存，再点击右上角“从 GitHub 同步”。这会替换本地草稿，已有编辑请先导出备份。附带资料可能不是最新数据，首次发布必须先同步。

## 使用流程

- 配队与视频：新增或编辑三人队伍、配置要求、版本、启动与循环说明以及多个视频。
- 推荐组合：维护完整三人组合、体系、主 C 与对应来源。
- 攻略来源：维护标题、UP 主、B站链接和版本；不能删除仍被组合引用的来源。
- 矩阵次数：分别勾选固定两次和本期额外两次角色，其他角色一次；不预设下一期。

保存本地草稿 → 预览并发布 → 检查差异 → 确认提交到 GitHub → 等待自动发布成功。

保存草稿不会改变公开网站。后台提交后，GitHub Actions 检查并发布成功，Wiki 才会更新。没有发布状态读取权限时，可以到 GitHub 仓库的 Actions 页面查看。

远端仓库被其他操作更新时，后台会停止覆盖；先导出草稿备份，再同步并重新合并修改。不执行强制推送。

## 数据与升级

草稿、最近 10 份备份和连接设置保存在 %LOCALAPPDATA%\BaichaoWikiAdmin，与 EXE 分离。可以从 v1.0 Python 启动版升级并继续使用同一账户的草稿和令牌；升级前退出旧程序并导出备份。

令牌由当前 Windows 账户加密保存，不包含在导出备份、ZIP 或公开仓库中。更换电脑或 Windows 账户需要重新填写令牌。

此工具不提供任意代码修改或角色原始技能数据编辑。退出程序和关闭电脑均不影响公开 Wiki。
